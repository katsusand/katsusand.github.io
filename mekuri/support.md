# サポート / Support

めくり / Mekuri

## お問い合わせ / Contact

ご質問・不具合のご報告・ご要望は、GitHub の Issues からお寄せください（GitHub アカウントが必要です）。

For questions, bug reports and requests, please open an issue on GitHub (a GitHub account is required).

**[お問い合わせ / Open an issue](https://github.com/katsusand/katsusand.github.io/issues/new)**

不具合のご報告には、お使いの機種・iOS のバージョン・アプリのバージョン（設定 →「このアプリについて」）を添えていただけると助かります。

For bug reports, please include your device, iOS version and app version (Settings → About this app).
